# RaselOMJ - Bangla ANSI Font

RaselOMJ একটি কাস্টমাইজড বাংলা ANSI (ASCII-based) ফন্ট, যা মূলত বিজয় কীবোর্ড এবং ক্লাসিক বাংলা টাইপরাইটিংয়ের জন্য উপযোগী করে অপটিমাইজ করা হয়েছে।

## ✨ Features
- **Classic Bangla Typing:** বিজয় (Bijoy) কীবোর্ড লেআউটের সাথে সম্পূর্ণ সামঞ্জস্যপূর্ণ।
- **ANSI Support:** পুরোনো অ্যাপ্লিকেশন, লিগ্যাসি সিস্টেম এবং টেক্সট কনভার্টর-এ ব্যবহারের উপযোগী।
- **Optimized Glyphs:** কাস্টম স্পেসিং এবং কার্নিং (Kerning) অপটিমাইজ করা হয়েছে।
- **Lightweight:** অত্যন্ত লাইটওয়েট ফাইল সাইজ, যেকোনো ডিভাইসে দ্রুত লোড হয়।

## 🛠️ How to Install
1. রিপোজিটরি থেকে `.TTF` ফাইলটি ডাউনলোড করুন।
2. ফাইলটিতে রাইট ক্লিক করে **"Install for all users"** সিলেক্ট করুন।
3. MS Word, Photoshop বা যেকোনো সফটওয়্যারে গিয়ে `RaselOMJ` সিলেক্ট করে টাইপিং শুরু করুন।

## 🔄 ANSI to Unicode Conversion
এই ফন্টটি ব্যবহার করে লেখা টেক্সট ওয়েবে ব্যবহারের জন্য Unicode এ কনভার্ট করতে আপনি যেকোনো Bijoy to Unicode কনভার্টার বা অনলাইন টুল ব্যবহার করতে পারেন।
