## 🔄 Why the Move? / কেন স্থানান্তর করা হয়েছে?

The `RaselOMJ` project was originally created as an Unicode Font to replace popular ANSI-based font for legacy systems. To provide a better, modern, and legally compliant experience for all users, we have completely rebuilt the project with the following improvements:

`RaselOMJ` প্রকল্পটি মূলত একটি ইউনিকোড ফন্ট হিসেবে তৈরি করা হয়েছিল, যার উদ্দেশ্য ছিল পুরোনো সিস্টেমগুলোতে ব্যবহৃত জনপ্রিয় (ANSI Font) গুলোকে প্রতিস্থাপন করা। ব্যবহারকারীদের জন্য একটি আধুনিক, উন্নত এবং প্রফেশনাল অভিজ্ঞতা নিশ্চিত করতে আমরা প্রজেক্টটি সম্পূর্ণ নতুন করে তৈরি করেছি:

- ✅ **Modern Unicode Support:** সম্পূর্ণ আধুনিক Unicode সাপোর্ট সংযোজন করা হয়েছে, যা যেকোনো ওয়েব, মোবাইল বা ডেস্কটপ অ্যাপে সরাসরি কাজ করবে।
- ✅ **Fresh Design:** ক্লাসিক বাংলা টাইপোগ্রাফির (Popular Ansi Font) সৌন্দর্য থেকে অনুপ্রাণিত হয়ে সম্পূর্ণ নতুন করে গ্লিফ ডিজাইন করা হয়েছে।
- ✅ **Open Source & Free:** নতুন প্রজেক্টটি **SIL Open Font License (OFL) v1.1** এর আওতায় সম্পূর্ণ ফ্রি এবং ওপেন-সোর্স হিসেবে রিলিজ করা হয়েছে।
- ✅ **Active Development:** ভবিষ্যতের সকল আপডেট, বাগ ফিক্স এবং নতুন ফিচার শুধুমাত্র নতুন রিপোজিটরিতেই যুক্ত হবে।
